# PhonePe Transaction Analytics Dashboard

An interactive Power BI dashboard designed to analyse digital payment transactions, user growth and regional performance across India.

## 1. Project Overview

This project analyses PhonePe digital payment data to understand transaction behaviour, geographical performance and user adoption trends.

The objective is to transform raw data into meaningful business insights using Power BI and DAX, helping identify transaction patterns, high-performing regions and opportunities for business growth.

## 2. Business Objectives

- Analyse transaction trends across different quarters.
- Identify states with the highest transaction amounts.
- Understand registered user growth across states and districts.
- Analyse transaction performance across different payment categories.
- Identify regional differences in digital payment adoption.
- Track business performance over time.

## 3. Tools & Technologies

- Power BI Desktop: Dashboard development and visualisation.
- DAX: Measures, KPIs and growth calculations.
- Power Query: Data cleaning and transformation.
- Data Modelling: Relationships between fact and dimension tables.

## 4. Dataset Description

The project uses PhonePe transaction and user datasets.

The datasets contain information about:

- State and district.
- Transaction amount.
- Transaction count.
- Registered users.
- App brands.
- Transaction types.
- Year and quarter.

The analysis covers quarterly data from 2018 to 2022.

## 5. Key Performance Indicators (KPIs)

The dashboard tracks the following metrics:

- Total Transaction Amount.
- Total Transaction Count.
- Average Transaction Value.
- Transactions per User.
- Total Registered Users.
- Quarterly Transaction Growth.
- New Registered Users.

## 8. Business Insights

Key findings from the analysis:

- Identify the states contributing the highest transaction value.
- Examine quarterly transaction growth from 2018 to 2022.
- Analyse registered user growth across different regions.
- Compare transaction performance across different categories.

## 9. Business Recommendations

Recommendations will be based on the findings from the dashboard.

- Identify regions with lower transaction activity.
- Investigate differences between user growth and transaction growth.
- Identify opportunities to increase digital payment adoption.
- Focus on regions with potential for higher transaction engagement.
